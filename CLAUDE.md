# JAMbo для Android-планшетов

Порт грувбокса JAMbo (iPad, Swift) на Android — для личного пользования.
Только планшеты, только альбомная ориентация. Pixel 7 — только для проверок.
Компьютера у пользователя нет: сборка только в облаке (GitHub Actions), APK ставится на устройство прямо по ссылке.

## Источник поведения и кода
Репозиторий djPtrvch/JAMbo, ветка `swift` — **только читать, ничего туда не писать**.
- `ios/JAMbo.swiftpm/Core` — звук, синты, секвенсор, мастер, MIDI-логика, проекты;
- `ios/JAMbo.swiftpm/UI` — экран и меню (SwiftUI);
- `CLAUDE.md`, `ios/CLAUDE.md`, `docs/ai/*.md` — правила и описание поведения.

Поведение JAMbo здесь не копировать: ссылаться на файлы djPtrvch/JAMbo (`docs/ai/…`), в своих `docs/ai` писать только отличия Android-версии.

## Принципы
- Общение с пользователем — по-русски; надписи в приложении — по-английски.
- Поведение — как в Swift-версии JAMbo, кроме того, что требует Android (записывается в docs/ai как отличие).
- Не добавлять функций сверх текущего этапа; перенос функций — только после решения пользователя.
- Звук считается в C++ (NDK), интерфейс — Kotlin + Compose.

## Стек
- Kotlin + Jetpack Compose (интерфейс), C++17 через NDK (звук), Oboe (AAudio, low latency, 48 kHz, exclusive).
- android.media.midi (USB, Bluetooth, виртуальные устройства).
- Ableton Link — официальная библиотека C++ (GPLv2; приложение для личного пользования), исходники скачивает `scripts/fetch-deps.sh` в `third_party/link` (не в git).
- Gradle 8.11 (без wrapper — версию задаёт CI), AGP 8.7, Kotlin 2.0, compileSdk/targetSdk 35, minSdk 29, ABI arm64-v8a.

## Структура
- `app/src/main/cpp/` — звук и Link (C++), JNI-мост `jni_bridge.cpp` → `Native.kt`.
- `app/src/main/java/app/jambo/android/` — Activity, экран (Compose), MIDI.
- `scripts/fetch-deps.sh` — внешние C++-зависимости.
- `.github/workflows/android.yml` — сборка debug-APK на каждый push.

## Правила кода
- Аудиоколбэк (`onAudioReady` и всё, что он зовёт): без выделения памяти, блокировок, логов, JNI и системных вызовов кроме часов. UI/MIDI → звук — атомарные значения; звук → UI — атомарные значения, UI опрашивает по таймеру.
- Нативный код собирается с оптимизацией и в debug-APK.
- Файл — не длиннее ~400 строк; Composable — короткие, по частям.
- Комментарии и документы — по-русски.

## Сборка
Только в CI (GitHub Actions) на каждый push; APK по постоянной ссылке:
`https://github.com/djPtrvch/JAMbo-and/releases/download/debug-<ветка>/jambo-debug.apk`. Подробно — docs/ai/build-ci.md.

## Коммиты
- Небольшие, сразу push. По-русски или по-английски, кратко.
- Без идентификаторов моделей в коммитах, коде и документах.

## Документация
- Этот файл — не длиннее 150 строк (мягкий порог 120): только суть.
- Подробности — по темам в `docs/ai/<тема>.md`; каждый файл — только своя тема, без дублирования с этим файлом и между собой. Читать файл, только когда задача касается его темы; нужный раздел искать по заголовку.
- Без импортов `@` для необязательных файлов.
- Markdown-документы (кроме этого файла при создании проекта): сначала предложить пользователю путь и текст, вносить после подтверждения. Поведение функций описывать после того, как сделано и проверено.
