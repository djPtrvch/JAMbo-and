# Открытые задачи

Срез по коду и проверкам **0.1.165**. Список собирает известные пробелы, порядок следующих этапов для него не согласован. Текущие функции описаны в [FEATURES.md](FEATURES.md).

## Проверки на устройстве

- **Ближайшая незакрытая проверка — Pixel 7, PATTERNS → ARRANGE.** Выделить всю группу рамкой, удержать клип, пройти кнопку ARRANGE и отпустить на таймлайне. Проверить свободное место и перекрытие, ROW REPEATS и один UNDO. Старый сбой при первом движении воспроизведён на стенде Compose, новая версия там проходит. Результата прогона APK 0.1.165 на Pixel 7 пока нет.
- Сверить на телефоне и планшете высоту дорожек FIX/SCALE, направление прокрутки и фейдера, M/S и сочетания STEPS/KNOBS/AUTO. Прогон этих изменений на реальном устройстве не зафиксирован.
- Для MIDI и SYNC остаются проверка TouchOSC → ADVERTISE с обычной нотой и сверка внешнего MIDI Clock на реальных портах. Жёлтая подсветка и наличие цели в Kotlin сами по себе не подтверждают паритет со всеми MIDI-целями Swift.

## Подтверждённые пробелы

| Область | Что осталось |
| --- | --- |
| ROLL | Кнопка пианоролла серая. Модель и операции есть в `core/model/Roll*.{h,cpp}`, окно Compose ещё не подключено. |
| PATTERNS | Отдельное управление видимостью нижней панели STEPS ещё не подключено к сетке. |
| Проекты | MIX и IMPORT ROWS в диалоге открытия отключены. Нужен перенос их действий из Swift, включая переход между проектами для MIX. |
| Общие настройки | Вкладки MIX, DEFAULTS и OUTPUT отсутствуют. В APPEARANCE не подключена FX ANIMATION. SAVE DEFAULT для мастер-эффектов и мастер-EQ уже есть. |
| Синхронизация | Сверить и подключить рабочий транспорт и квантование к Ableton Link. Проверка исходного спайка относится к отдельному пути. |
| EQ и мониторинг | В Android не найден интерфейс EQ COMPARE и коррекции наушников CORRECT. Наличие DSP в `core/monitor/` не подтверждает перенос настроек OUTPUT и мониторных маршрутов REF. |

## Требуется сверка

- Ранний [handoff.md](handoff.md) перечисляет отдельные пробелы библиотеки, параметров сэмплера и захвата нот. Он предшествует поздним изменениям. Перед планированием этих задач проверить конкретные сценарии по Swift и текущим обработчикам Android.
- Полный паритет всех жестов ARRANGE/AUTO, целей MIDI LEARN, совместимость каждого вида проекта между устройствами и пороги производительности не подтверждены сплошным прогоном. Проверять затронутые сценарии при правках, отдельно отмечать платформу и версию.
