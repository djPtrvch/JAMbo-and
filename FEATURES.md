# Функции и управление

Состояние по коду и сборке **0.1.165**. Работоспособность конкретных жестов на устройстве указана в [ROADMAP.md](ROADMAP.md). Точки входа для правок перечислены в [ARCHITECTURE.md](ARCHITECTURE.md).

## Игра и редактирование

- PLAY ведёт транспорт. REC записывает ноты экранной клавиатуры и MIDI во время игры. QUANTIZE и OVERDUB управляют записью, удержание клавиши задаёт длину. При отмене касания или уходе с экрана экранные ноты отпускаются.
- Тап по шагу переключает триг, удержание позволяет редактировать шаг и его p-lock. На ударных и сэмпловых дорожках DRUM STEP PAINT позволяет провести пальцем по нескольким шагам. Страницы переключаются миниатюрами и стрелками. SPEED меняет скорость клипа.
- SCALE и ROOT задают гамму и тонику. CHORD включает аккорды, долгое нажатие открывает выбор типа или стиля. В режиме ARPEGGIATOR доступны RATE, GATE, направления, OCTAVES и LATCH. ARP может записывать ноты через REC. В меню клавиатуры есть октавы, SWING, KEY VELOCITY и OVERDUB.
- FX и MOD открывают группы ручек. LFO/ENV назначаются удержанием и поворотом, SHIFT открывает дополнительные действия. MORPH позволяет менять параметры и возвращать их, включая режим для всех дорожек через SHIFT + MORPH. RANDOM генерирует вариации ударных, мелодии, нарезки и ансамбля по стилю. UNDO/REDO возвращают контекст дорожки, клипа и страницы.

## PATTERNS и ARRANGE

| Действие | Результат |
| --- | --- |
| Тап по ячейке / строке PATTERNS | Запуск клипа / строки. В режиме игры запуск планируется транспортом. Удержание ячейки открывает клип для редактирования. Свайп вверх по ячейке и двойной тап по строке открывают меню. |
| Стрелки PATTERNS, LOOP ROW | VIEW прокручивает окно, SWITCH переключает строку. LOOP ROW удерживает текущую строку. В меню сетки задаются стартовая строка, поведение в конце и действие «+». |
| Рамка в PATTERNS | Потяни из зазора или, на смартфоне, из пустой ячейки. Рамка по колонке номеров выбирает целые строки. Удержи заполненный клип внутри выделения и протяни на кнопку ARRANGE, затем отпусти над таймлайном. TO ARRANGE доступен в меню ячейки и строки. |
| Вставка в ARRANGE | Выделенные строки идут сверху вниз, клипы одной строки — параллельно. ROW REPEATS учитывает повторы строк. При пересечении с блоками меню предлагает HERE, INSERT и TO END. Перенос целиком входит в одну операцию UNDO. |
| Таймлайн ARRANGE | GRID и SNAP выбирают деления и привязку. Стрелка к черте возвращает курсор, LOOP включает отмеченный диапазон. Блоки можно выделять, тянуть, обрезать, делить, копировать и дублировать. На линейке есть секции. |
| Дорожки ARRANGE | FIX подгоняет высоту под видимую область. При скрытом STEPS кнопка под измерителем переключает COMPACT / EXPANDED. В SCALE вертикальный жест двумя пальцами меняет высоту, горизонтальный — масштаб времени. FOLLOW PLAYHEAD включает автопрокрутку. |
| Заголовки ARRANGE | Тап выбирает дорожку, двойной тап открывает её меню. M и S переключаются тапом. Свайп вверх/вниз прокручивает дорожки. В высоких строках горизонтальный жест по фейдеру меняет громкость. |
| STEPS, KNOBS, AUTO, REF | STEPS показывает нижние органы управления, KNOBS сохраняет размер обычной панели. AUTO открывает кривые автоматизации с редактированием и записью. REF загружает референс с переключением A/B. |
| Запись PATTERNS в ARRANGE | Нажми ● ARR в боковой колонке PATTERNS для подготовки записи. Запуски клипов во время игры записываются на таймлайн. ARRANGE REC START задаёт старт по курсору или с начала. |

## Звук, сэмплы и микшер

- Меню звука выбирает синтезатор или SAMPLER. Библиотека позволяет загружать, предварительно слушать и организовывать сэмплы, сохранять пресеты. Доступны собственные звуки шагов и воспроизведение по нарезке.
- Редактор сэмпла показывает форму волны. Доступны запись, сохранение, CUT, TRIM, NORMALIZE и MONO. Удержание метки открывает выбор роли RANDOM, клавиша назначает метке ноту. Настройки SLICE NOTES выбирают CHROMATIC / SCALE. В WARP есть ручные метки, FILE BPM, AUTO WARP, CLEAR WARP и шаг сетки. Вверх/вниз по свободному участку волны меняет масштаб, движение вбок прокручивает. [Особенности касаний и маркеров](docs/ai/ui.md#редактор-сэмплов).
- MIX показывает каналы, уровни, панораму и анализ. Есть MUTE/SOLO, перестановка дорожек, запись стемов и мастера. MST открывает SAT, COMP, CLIP и LIM. В EQ доступны полосы, динамика, LISTEN и пресеты. У модулей мастера и мастер-EQ есть SAVE DEFAULT. Правый измеритель показывает уровень, LUFS, пик и регулятор. CPU в верхней панели показывает загрузку аудиоколбэка.

## Контроллеры, проекты и настройки

- MIDI LEARN подсвечивает выбранную цель жёлтым. Доступны назначения для транспорта, ручек, клавиатуры, шагов, страниц, треков, MIX/MST и PATTERNS, включая отдельные команды ARRANGE. USB, BLE и ADVERTISE описаны в [заметках о MIDI](docs/ai/midi.md). SYNC содержит MIDI Clock с входом, выходом, START/STOP и смещением. Статус привязки Ableton Link к транспорту см. в [архитектуре синхронизации](ARCHITECTURE.md#синхронизация).
- PROJECTS управляет NEW, LOAD, SAVE, SAVE AS, переименованием и удалением. Autosave работает при редактировании и уходе в фон. IMPORT / EXPORT `.jambo` переносит проект с его медиа. EXPORT SONG рендерит аранжировку целиком в WAV или M4A, с выбранным хвостом эффектов. При экспорте отключаются петля, REF и MIDI out.
- SETTINGS содержит RECORD, SAMPLER, ARRANGE, MORPH, RANDOM, LEVEL, DUCK, APPEARANCE и AUDIO ENGINE. LEVEL выбирает абсолютную громкость или относительное ослабление. DUCK настраивает отправки в эффекты. APPEARANCE задаёт тему, масштаб дисплеев мастер-эффектов и ориентацию групп ручек. AUDIO ENGINE показывает параметры фактического потока.
