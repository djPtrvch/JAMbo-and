# Перенос Core
- Весь Core (звук, секвенсор, модель, проекты, MIDI-маппинг) — C++17 в `app/src/main/cpp/core/`, 1:1 по файлам `ios/JAMbo.swiftpm/Core` (ветка swift JAMbo): те же имена, константы и порядок вычислений; Double там, где Double в Swift.
- Проверка — `tests/` на Linux: сверка с `ios/CoreTests/golden` (скачивает `scripts/fetch-test-deps.sh`, только чтение), критерий как в Swift: по отсчётам ≤ −60 dB или третьоктавные полосы ±0,5 dB; в CI — задача `core-tests`.
- Без `-ffast-math` (проверки NaN и совпадение с эталонами).
- Перенесено: FX — Delay, Reverb, Drive (с DriveTables), Duck; движки — KICK, ANALOG, FM, WTABLE, SUB (JamboVoice), SNARE, HAT, CLAP, PERC (JamboDrums), TEXTURE, GRANULAR (с TexGran), таблицы и встроенные wavetable. Эталоны: 36 из 36 (fx_*, j16–j19), −102…−315 dB; ударные — тесты свойств (как DrumEngineTests). Без проверки: SUB и режимы модуляции ANALOG. TEXTURE и GRANULAR — тесты свойств (уровень, ровность; GRANULAR — NaN, лимит зёрен); пик GRANULAR на крайних ручках до +6,5 dBFS — сверить со Swift на слух.
- Справочники: Params (+Fmt), SynthEngines, FilterType, Scales — тест `tables_test.cpp`; KnobDefaults и миграции Filter, которым нужен проект, — с моделью.
- Модель проекта: Step, Clip, Track, Project и типы полей (поля TrackMore и ProjectMore — обычные поля), KnobDefaults без JSON, `Track::setSynth`, `Project::migrateFilter` — тест `model_test.cpp`.
- Файл проекта: ProjectFormat (`jambo-swift`, JSON как у iPad; nlohmann/json — `scripts/fetch-deps.sh`), чтение по правилам Swift Codable (`model/Json.h`), repair и миграции версий 3–10, пресеты синта и KnobDefaults — тест `coding_test.cpp`. Хранилище проектов на диске — позже.
- Правки и UNDO: History (место правки — `std::any`), TrackEdits, RollEdits, Roll, StepNotes — тест `edit_test.cpp` (EditTests, MorphTests).
- Аудиоядро: SoundSnapshot (с TempoDetect, Onsets, WarpMap), ModEngine, SynthVoices + RenderPool (MULTICORE), SeqSnapshot, Launcher, Sequencer, StemRing — тесты audio_test, synth_test, seq_test; Sampler для секвенсора — интерфейс SeqVoices.
- Сэмплер (голоса, микшер, MIDI OUT, предпрослушка, WARP), таймстретч BEAT и NORMAL, FxRack — тест sampler_test.cpp; EQ (EqUnit с M/S и Dynamic, EqListen, спектры), уровни и LUFS, замеры колбэка — эталоны eq_* (22 из 22), тест eq_test.cpp.
- Мастер: сатуратор, компрессор, клиппер, лимитер, цепочка MasterChain — эталоны mst_* (19 из 19), тест master_test.cpp.
- AudioCore + CoreEvent (снимки — сырыми указателями через очереди, освобождение через 0,5 с), Arpeggiator, TestTone, Capture, RefPlayer, Headphone Monitor (MonitorDesign, RoomIR, RoomConv, MonitorChain; ресурсы комнат — fetch-test-deps) — тесты arp_test, monitor_test, core_test, launch_test, fxroute_test, mod_core_test.
- Не перенесено: HeadPack, PhonesProfile/PhonesEq, пресеты EQ и мастера, переход MIX (Project::mixed, blendMaster), правки варпинга Track, SampleEdit, хранилище проектов; часть тестов Swift через ядро — список в handoff.md.
